# Calculadora Avícola RM

App web gratuita de **RM Agroinversiones** para hacer en segundos las cuentas de un galpón de gallinas ponedoras: producción, alimento, costos y ganancia, simulador, levante, espacio y equipos, agua, medicamento en agua, mezcla de alimento, luz, mortalidad, proyección del lote, clasificación del huevo, conversiones, inversión y retorno, y gallina de descarte.

Se instala en el celular como una app y funciona sin internet. Para llevar el registro diario completo del lote: **RM Postura** → https://rm-postura.expo.app
